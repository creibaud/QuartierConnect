Bienvenue sur QuartierConnect, l'espace en ligne de votre quartier. Cette page vous accompagne pas à pas pour créer votre compte, sécuriser votre connexion et rejoindre votre quartier. Prenez le temps qu'il vous faut : chaque étape est simple.

## Vue d'ensemble

La mise en route suit toujours le même parcours : vous créez votre compte, vous activez la double authentification en scannant un QR code, puis vous renseignez votre adresse pour être rattaché à votre quartier. Le schéma ci-dessous résume ce chemin.

## Étape 1 : créer votre compte

L'inscription se fait en deux temps sur la page d'inscription. La première partie consiste à renseigner votre profil.

Vous indiquez :

- votre **prénom** et votre **nom** ;
- votre **adresse e-mail** ;
- votre **mot de passe**, que vous saisissez deux fois pour confirmation ;
- votre **numéro de téléphone**.

Le formulaire vérifie automatiquement le format de votre e-mail, la longueur minimale du mot de passe et le fait que les deux saisies du mot de passe soient identiques.

### Le consentement, une étape obligatoire

Avant de continuer, vous devez cocher la **case de consentement RGPD**. Sans cette validation, la création du compte est bloquée. C'est votre accord pour que vos données soient traitées.

## Étape 2 : activer la double authentification

Pour protéger votre compte, QuartierConnect utilise une **double authentification** (aussi appelée TOTP). En plus de votre mot de passe, un code à six chiffres vous sera demandé à chaque connexion. Ce code change toutes les quelques secondes, ce qui rend votre compte beaucoup plus difficile à pirater.

Après avoir validé votre profil, l'application affiche un **QR code** ainsi que le secret correspondant en clair, que vous pouvez copier.

Pour l'activer :

1. Installez sur votre téléphone une **application d'authentification** si vous n'en avez pas déjà une. Les plus connues sont Google Authenticator, Aegis ou FreeOTP.
2. Ouvrez cette application et **scannez le QR code** affiché à l'écran. Si vous préférez, vous pouvez saisir le secret à la main en le copiant.
3. Votre application d'authentification génère alors un **premier code à six chiffres**. Saisissez-le dans QuartierConnect pour confirmer l'appairage et finaliser la création de votre compte.

> Conservez précieusement l'accès à votre application d'authentification : c'est elle qui produit le code demandé à chaque connexion.

## Étape 3 : se connecter

Une fois votre compte créé, la connexion se déroule en deux étapes simples :

1. Saisissez votre **adresse e-mail** et votre **mot de passe**.
2. Saisissez le **code à six chiffres** affiché sur votre application d'authentification.

Si vos identifiants sont erronés ou si le code n'est pas valide, un message d'erreur explicite s'affiche pour vous aider à corriger.

## Étape 4 : rejoindre votre quartier

Pour accéder au contenu local (services entre voisins, événements, votes…), votre compte doit être rattaché à un quartier. Après votre première connexion, si aucune adresse n'est encore associée à votre compte, l'application vous présente un écran de **saisie d'adresse avec autocomplétion**.

Renseignez votre adresse en vous aidant des suggestions proposées. Deux cas de figure sont possibles.

- **Votre adresse est dans un quartier couvert.** Votre compte est automatiquement rattaché à ce quartier, et vous accédez aussitôt à votre tableau de bord.
- **Votre adresse est reconnue mais hors de tout quartier couvert.** Vous êtes alors dirigé vers un écran « couverture en attente ». Votre adresse est enregistrée pour que l'équipe d'administration puisse étendre la couverture à votre zone.

Le schéma ci-dessous illustre ces deux cas de figure.

<Mermaid chart={`

Dans tous les cas, vous pouvez **corriger votre adresse à tout moment** si vous vous êtes trompé ou si vous déménagez.
