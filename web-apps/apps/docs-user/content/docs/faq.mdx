Vous trouverez ici des réponses courtes aux questions que se posent le plus souvent les habitants. Chaque réponse renvoie, quand c'est utile, à l'endroit exact de l'application où agir.

## Connexion et double authentification

Votre compte est protégé par une double authentification : à chaque connexion, après votre e-mail et votre mot de passe, vous saisissez un code à six chiffres généré par une application d'authentification (Google Authenticator, Aegis, FreeOTP, etc.).

### J'ai perdu mon code, mon application d'authentification ne génère plus le bon code

Le code à six chiffres n'est jamais fixe : il change toutes les 30 secondes. Si le code est refusé, vérifiez d'abord que l'heure de votre téléphone est bien réglée automatiquement, puis attendez l'apparition d'un nouveau code avant de réessayer.

Tant que vous êtes connecté, vous pouvez gérer votre double authentification depuis la page **Profil**, dans la carte **Sécurité**, qui rassemble la gestion du mot de passe et de la double authentification.

### J'ai changé de téléphone

Sur votre nouveau téléphone, installez à nouveau une application d'authentification, puis reconfigurez la double authentification depuis la page **Profil**, carte **Sécurité**. Vous scannez le QR code proposé (ou copiez le secret affiché), puis confirmez avec le premier code à six chiffres, exactement comme lors de votre inscription.

> Bon réflexe : reconfigurez votre double authentification **avant** de vous séparer de votre ancien téléphone, pendant que vous êtes encore connecté.

## Mon adresse et mon quartier

Pour accéder au contenu local, votre compte doit être rattaché à un quartier, déterminé à partir de votre adresse.

### Mon adresse est « hors couverture »

Si votre adresse est reconnue mais ne se trouve dans aucun quartier déjà couvert, vous arrivez sur un écran **« couverture en attente »**. Votre adresse est alors enregistrée pour que l'équipe d'administration puisse étendre la couverture à votre zone. Vous pouvez à tout moment corriger votre adresse si vous vous êtes trompé.

## Comment fonctionnent les points ?

La page **Points** affiche votre solde et l'historique de vos transactions : points reçus, points envoyés et paiements de services.

- Vous pouvez **transférer des points** à un voisin : recherchez le destinataire, saisissez un montant et une note facultative, puis validez. Votre solde et votre historique se mettent à jour immédiatement.
- Certains services entre voisins sont **payants en points**. Le nombre de points est calculé à partir du barème du service ; un multiplicateur peut y être associé. Lorsqu'une réservation payante est acceptée, un contrat est généré : c'est la **dernière signature** (celle qui rend le contrat signé par les deux parties) qui déclenche automatiquement le transfert de points et scelle l'échange. Le mouvement de points a donc lieu à la signature finale, et non après coup.

## La confidentialité de mes données (RGPD)

Vos données personnelles sont protégées et vous en gardez le contrôle depuis la page **Profil**, carte **Confidentialité (RGPD)**.

### Puis-je récupérer une copie de mes données ?

Oui. L'option **Export des données** télécharge l'ensemble de vos données personnelles dans un fichier structuré (droit à la portabilité, article 20 du RGPD). L'archive contient notamment votre profil, vos incidents, vos services, vos événements, vos contrats, vos points et vos conversations.

Certaines informations sensibles ne sont **jamais** incluses dans l'export, comme votre mot de passe (qui n'est de toute façon stocké que sous forme chiffrée) ou le secret de votre double authentification.

## Comment supprimer mon compte ?

Depuis la page **Profil**, carte **Confidentialité (RGPD)**, choisissez **Suppression du compte**. La suppression est **définitive** et vous devez la confirmer en saisissant votre code à six chiffres, afin d'éviter toute suppression accidentelle.

À la suppression, vous êtes immédiatement déconnecté. Vos signalements d'incidents peuvent être conservés le temps nécessaire à la modération, tandis que le reste de votre profil est retiré de la plateforme.
